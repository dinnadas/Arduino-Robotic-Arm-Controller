This project implements a simple and flexible Arduino-based robotic arm controller using servo motors. The code allows smooth and precise control of five servos, which operate the base, shoulder, elbow, gripper, and an optional rotator of the robotic arm. Each servo can be moved to a target angle gradually, ensuring smooth motion suitable for tasks such as pick-and-place operations or small-scale automation.

Key features include:

Individual functions to control each servo (base, shoulder, elbow, gripper).

Adjustable speed for smooth movement of the arm.

Easy-to-modify initial positions to match your arm’s configuration.

Modular design, allowing future expansion (e.g., additional servos or sensors).

This project is ideal for beginners and hobbyists interested in robotics, Arduino programming, and mechanical automation.
